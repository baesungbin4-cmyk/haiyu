# Performance Test Plans

These files are templates only. They must not be reported as successful
performance results until executed and measured in the target environment.

- `mqtt_throughput_plan.md`: MQTT QoS1 throughput/reliability plan.
- `jmeter_plan.md`: backend concurrency and latency plan.

All unmeasured values stay marked as `拟开展/未验证`. Numeric thresholds are
targets from the project contract unless a dated test report says measured.
