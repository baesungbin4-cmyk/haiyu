# Backend JMeter Plan

Status: `拟开展/未验证`

## Scope

- REST endpoints: health, latest alerts, historical alerts.
- WebSocket rendering is measured separately in the frontend section of the
  test report.
- No backend latency value is claimed until JMeter or equivalent output is
  attached.

## Procedure

1. Configure API token and isolated test data.
2. Run staged concurrency levels with measured response percentiles.
3. Record mean, p95, p99, errors, and environment details.
